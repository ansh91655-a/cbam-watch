# cbam-watch

EU 탄소국경조정제도(CBAM) 규제동향 사이트를 위한 저장소입니다.

- `originals/` 공개된 EU 원문(법령 통합본, 가이던스 등)의 사본과 판 이력, 판 사이의 비교 결과
- `tools/` 내려받기, 해시 계산, 본문 추출, 판 비교, 용어 검사, 게시 데이터 만들기 같은 정해진 작업을 하는 프로그램
- `language/` 국문 표기 기준(용어집, 문체 기준)
- `site/` 공개 사이트의 화면 파일
- `data/` 사이트에 게시한 데이터의 사본

원문의 저작권과 재이용 조건은 각 출처를 따릅니다. 이 저장소의 정리와 번역은 자동으로 만든 것이며, 정확한 내용은 반드시 원문에서 확인해야 합니다.
