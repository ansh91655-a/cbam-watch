# 국문 PDF에 쓰는 글꼴

`tools/pdfko`가 원문 PDF와 같은 자리에 번역을 찍을 때 쓰는 글꼴입니다. 모두 SIL Open Font License 1.1로 배포되며, 파일은 고치지 않고 그대로 두었습니다.

| 글꼴 | 쓰임 | 받은 곳 | 허락글 |
|---|---|---|---|
| Pretendard (Regular, Bold) | 민글꼴 문서(Arial, Calibri 등)의 번역 | npm `pretendard` 1.3.9 | LICENSE-Pretendard.txt |
| 나눔명조 (Regular, Bold) | 부리글꼴 문서(Times New Roman 등)의 한글 | npm `@expo-google-fonts/nanum-myeongjo` 0.4.1 | LICENSE-NanumMyeongjo.txt |
| Tinos (Regular, Bold) | 부리글꼴 문서의 로마자·숫자·문장부호 | npm `@expo-google-fonts/tinos` 0.4.2 | LICENSE-Tinos.txt |
